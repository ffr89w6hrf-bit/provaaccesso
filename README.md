# SportNOW

Prototipo iniziale di SportNOW.

## Cosa fa
- mostra attività sportive vicine
- filtra per sport
- cerca per sport o luogo
- permette di segnarsi come partecipante
- permette di creare una nuova attività
- include una semplice vista mappa
- è predisposta come PWA installabile

## File da caricare nella root del repository
- `index.html`
- `styles.css`
- `app.js`
- `manifest.json`
- `sw.js`

Per vederla online con GitHub Pages:
1. apri il repository
2. vai in Settings
3. Pages
4. sotto Build and deployment scegli `Deploy from a branch`
5. seleziona branch `main` e cartella `/ (root)`
6. salva
